# Tihulu Star Trail v0.1.2 archive

This folder preserves the released desktop installers that existed before the
manual thumbnail and drag-and-drop review improvements.

- `setup-macos-dmg.sh` downloads the matching Apple Silicon or Intel DMG and
  opens it for installation.
- `setup-linux-appimage.sh` downloads the x86_64 AppImage and its FUSE-free
  launcher.
- `SETUP.md` contains the complete, version-specific installation guide and
  checksum links.

The exact release assets remain available at:
https://github.com/Tihulu/tihulu-star-trail/releases/tag/v0.1.2
