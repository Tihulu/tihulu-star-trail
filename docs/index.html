Parameter Guide

Group Threshold
0.60-0.70 is loose, 0.72-0.82 is balanced, 0.90+ is strict and may split real sets.
Preview Side
64 is fast. 96-160 gives better grouping clues but uses more browser memory.
Output Max Side
Sets the longest output edge when Keep Original Size is off. Turn Keep Original Size on to export at the source dimensions with no resizing or stretching.
Image Format
JPEG is smaller for sharing. PNG is lossless and larger, useful for editing later.
Image Quality
80-90 keeps files small. 92-100 preserves faint trails with larger JPEGs.
FPS
12-18 feels calm, 24 is cinematic, 30-60 is smoother but needs more frames.
Video Max Side
1080-1920 is good for sharing. 2160-3840 is sharper but slower and uses more memory. Turn Keep Original Video Size on to use the source photo dimensions with no video downscaling or stretching.
Video Format
WebM is fastest. Chromium and other browsers record MP4 directly when native MP4 is supported; otherwise MP4 records WebM first, then converts through FFmpeg WASM.
Video Quality Mbps
4-8 works for previews, 10-20 is cleaner, 25+ is best for 4K-style exports.
Time Metadata
Uses camera EXIF capture time when available, otherwise file date. Photos without a usable time stay separate rather than being merged across unknown dates.
Time Window Hours
Photos taken within this many hours are more likely to stay in the same group.
Group Photo Order
Drag photos inside Group Photos to set the timelapse order. Trail stacking is order-independent; move or remove photos to change which frames build the trail.
